OmniCaster — Seal Sorcery VFX Fix
=================================

Copy this folder's "parts" directory into your loose-file mod directory.
Keep the directory name: the installed files must be under "parts".

This optional pack adds sorcery VFX attachment points 122, 181, and 301
where missing from all vanilla base-game and DLC Sacred Seal models, for
both right and left-hand use.
It does not change meshes, materials, textures, or any existing attachment.

Requirements:
- me3, ModEngine2, or another loader that supports loose game files
- offline play with EasyAntiCheat disabled

To install this with me3: extract the "parts" folder in the "eldenring-mods" directly.
To install this with ModEngine2: extract the "parts" folder in the "mod" folder within your ModEngine2 directory.

Elden Mod Loader can load OmniCaster.dll, but it cannot load these model
files by itself.

Compatibility:
- A mod that replaces one of the same seal model files will conflict.
- Custom seal models from overhauls also need attachment points 122, 181,
  and 301 added.
- The DLL can still be used without this pack; only the affected seal-cast
  sorcery VFX will remain absent.
